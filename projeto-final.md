## SME0828 - Introdução à Ciência de Dados

## Projeto final

Prof. Francisco Rodrigues

Grupo: No máximo 3 pessoas (pode ser menos). Coloque o nome de todos no projeto. Apenas um aluno precisa enviar.

- Escolha uma base de dados do seu interesse e desenvolva um projeto completo de Ciência de Dados.

- O projeto deve ter uma questão fundamental que ser que resolver.

- Exemplos:

- É possível classificar pacientes de acordo com os seus atributos?

- Qual o melhor método para predizer a evolução dos preços de bitcoins?

- Como classificar mensagens de redes sociais de acordo com o posicionamento político dos usuários?

- Feito isso, você deve seguir o método científico, pois Ciência de Dados é mais Ciência do que dados.

- Faça a pergunta, colete os dados, analise os dados e chegue ao resultado, confirmando ou refutando a hipótese.

- A hipótese pode ser a pergunta dos exemplos acima.

- Na execução do projeto, siga os seguintes passos (você decide a ordem e quais passos são necessários):

- dados faltantes. 1.Comece preparando os dados, removendo atributos irrelevantes e corrigindo

- 2.Realize a descrição estatística dos dados.

- 3.Verifique se há algum padrão relevante.

- 4.Verifique se o problema é de classificação, regressão, agrupamento ou agrupamento semi-supervisionado.

- 5.Escolha os métodos e faça o ajuste e seleção dos modelos.

- 6.Compare os modelos usando diferentes métricas de avaliação.

- 7.Verifique se é possível melhorar os resultados usando métodos de projeção, seleção atributos ou transformação dos dados.

- 8.Obtenha os resultados finais.

- 9.Discuta os resultados, indicando os principais resultados e o que pode ser feito para melhorara-los.

- 10.Faça um sumário do projeto todo.

- Importante: Capriche nos gráficos, pois é onde estão os resultados principais.


•Desafios que podem surgir:

- Desbalanceamento de dados.

- Dados não independentes.

- Excesso de atributos.

- Poucas observações.

- Dados incompletos.

- Presença de outliers.

- Variáveis irrelevantes.

- A nota será pela completeza da análise e não pelo resultado. Usem os conceitos que aprendemos no curso e reflitam sobre diferentes estratégias.
